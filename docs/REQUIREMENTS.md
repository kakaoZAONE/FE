# 확정 요구사항

## 사용자 흐름
1. 메인 → 샘플 둘러보기(`/samples`) → 샘플 상세 (로그인 불필요)
2. 메인 → 내 소재 등록 → 사진 업로드와 기본 정보 입력 → AI 특성 분석 → 특성 확인·수정 → 최종 확인 → 놀이 장면 생성(생성 중 / 실패 / 완료) → 결과
3. 결과 → 저장(로그인) · 재탐색 · PDF 저장 · 자원랩 문의 → MY에서 저장 결과 관리

## 로그인 · 게스트 세션
- 공개 페이지와 샘플은 로그인 없이 이용할 수 있다.
- 내 소재 탐색의 비회원 이용 범위는 API 정책을 따른다(**미확정**).
- 게스트 세션은 내부 기능이며 관리 화면이 없다. 로그인할 때 게스트 결과가 사라지지 않게 한다. 세션 만료와 소유권 이전은 백엔드 명세를 따른다.

## 샘플 탐색
- 샘플 4종(종이관, 지퍼 자투리, 플라스틱 병뚜껑, 포장 완충재)은 사전 검증된 완전한 정보다. 미확인, 확인 필요, 추정 같은 상태를 붙이지 않는다.
- 기업 제공 정보와 AI 분석 특성을 구분하고, 탐색·변형·조합 세 장면을 제공한다.
- AI 장면을 실제 사례나 검증된 교육 사례처럼 표현하지 않는다.

## AI 결과 생성
- 상태: 요청 / 진행 중 / 완료 / 실패 / 부분 실패 / 재시도
- API가 주지 않는 진행률이나 소요 시간은 표시하지 않는다. 중복 요청을 막고, 오류가 나도 입력값을 유지한다.

## PDF
- 프론트엔드에서 생성한다(백엔드 API 추가 없음). 순서는 저장 정보 확인 → 미리보기 → 생성 → 다운로드 → 실패 처리.
- 한글 폰트, 잘림, 이미지 누락을 확인한다. 해외 사례와 내부 데이터는 넣지 않는다.

## 문의 · 외부 링크 (`lib/core/external_links.dart`)
- ZAONE LAB 소개: https://www.zaone.org/zaone-lab (200 확인)
- 자원 공식 문의: https://www.zaone.org/contact (200 확인)
- 문의 완료를 허위로 표시하지 않는다.

## 오류 처리
- 이미지 로딩 실패, 네트워크 오류, 입력 검증 실패 시에도 입력 상태를 유지하고, 재시도 경로를 제공한다.

## 제외된 기능
- 해외 실제 활용 사례(섹션, 개수 배지, 기관명, 출처 링크, 원문, evidenceCases)
- 내부 수집 데이터와 원본 데이터셋의 프론트 포함
- 게스트 세션 관리 화면

## 미확정
- 이용약관과 개인정보처리방침 문서 및 링크
- 비회원 내 소재 탐색 범위
