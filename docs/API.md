# API 연동 현황

## 명세 위치
- 저장소에는 API 명세, Swagger/OpenAPI, 백엔드 문서가 **없다**(2026-11-24 확인).
- ERD는 팀 ERDCloud에 있다(링크는 `docs/internal/LINKS.md`). 엔드포인트, 메서드, 인증 방식, 오류 코드는 **미확정**이다.

## 실제 연동 Endpoint
- 없음.

## Mock 사용 현황
| 기능 | 데이터 | 위치 | 비고 |
|---|---|---|---|
| 샘플 결과 4종 | 정적 데이터(팀 구현) | `lib/features/sample_result/sample_result_page.dart` `_items` | 공개용 샘플. API 확정 시 교체 여부 결정 |
| 로그인 | 연동 없음 | `lib/widgets/login_dialog.dart` | 입력 검증 후 "준비 중" 안내만 표시(로그인 성공을 표시하지 않음) |

## 백엔드에 확인할 사항
- 인증 방식(기업명+비밀번호 → 토큰?), 토큰 저장 위치, 만료 처리
- 게스트 세션 발급 방식과 로그인 시 결과 소유권 이전
- 소재 이미지 업로드(형식, 용량, presigned 여부)
- AI 분석과 장면 생성 상태값(폴링/웹소켓, 부분 실패 표현)
- 결과 저장, 목록, 상세, 삭제와 권한
- 샘플 데이터를 API로 제공할지 여부

## 환경
- Base URL은 `--dart-define=API_BASE_URL=...`로 주입할 예정이다(개발/테스트/배포 구분). 클라이언트에 서버 전용 키를 넣지 않는다.
