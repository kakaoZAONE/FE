## 2026-11-27 — C3 PDF 저장 (직접 생성)

### 이전 방식의 문제
- `window.print()`로 만든 PDF: **1쪽, 이미지 1장**(Flutter 캔버스 캡처). 장면·소재 정보·안내 문구 없음, 글자 선택 불가.

### 바뀐 방식
- `lib/features/result/result_pdf.dart`: `pdf` 패키지로 A4 PDF 생성 → `lib/core/save_file.dart`(Blob 다운로드) → C3-1 알림 '✓ PDF를 저장했습니다 · 파일 이름 · 파일보기'(새 탭)
- 한글: `assets/pdf_fonts`(Noto Sans KR 400/700, 한글 11,172자 전체 · `tool/pdf_fonts.sh`). PDF를 만들 때만 불러옴
- 사진: 웹은 브라우저 캔버스로 긴 변 1200 JPEG 변환 후 삽입(`lib/core/jpeg_encode.dart`). RGBA로 넣으면 웹에서 Dart 압축이 2분 넘게 걸려 교체

### 확인 (헤드리스 Chrome · 1440)
- ✅ 샘플 종이관: 생성 0.55초 · 369KB · 3쪽 · 글자 선택 가능 · 장면 사진 3장 포함
- ✅ 사용자 결과(앱 폰트에 없는 글자 '뷁쀍' + 소재 정보 표 3종): 3쪽, 표 제목과 내용이 같은 쪽
- ✅ '다운로드' → '만드는 중…'(버튼 잠김) → 창 닫힘 → C3-1 알림
- ✅ 위젯 테스트 `test/result_pdf_test.dart`(PDF 헤더·쪽 수·파일 이름)
- ⬜ 실제 기기: iOS Safari · Android Chrome · 카카오톡 인앱 브라우저의 다운로드 동작(Blob 다운로드를 막는 인앱 브라우저가 있음) — 수동 확인 필요
- ⚠️ 로컬 `flutter build web`이 가끔 `FontManifest.json`·`manifest.json`을 빠뜨림(다시 빌드하면 정상). 배포 전 `build/web/assets/FontManifest.json` 확인
